The two validation agents are automated, rule-based checks that run beside the feed pipeline without ever sitting in the live data path or changing the data they read. The Integrity agent examines every 50 and 200 millisecond record before it reaches clients, looking for broken message sequences, crossed or stale order books, impossible values and updates the book could not apply. It then stamps each record valid, degraded or invalid, so that probabilities are withheld whenever the underlying data cannot be trusted, and it produces a dated incident report that auditors and clients can rely on. The Evaluation agent answers the commercial question of whether the feed adds value. CME staff run a prospective client’s own trading logic against held-out historical days, with and without the pilot’s metrics and probabilities, under conservative assumptions for trading costs and delay, and the agent reports the difference with a statistical confidence range. It also tests whether the client’s logic peeks at the future, in which case it refuses to publish any performance figures, and it runs client code in a restricted environment. Both produce reproducible, summary-ready reports and use no AI-generated text. To date they have been tested only on synthetic data, not on real CME data.
